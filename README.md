## Technologies I have used

### Portfolio website

The portfolio is a frontend-only React application built with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS 4**. The interactive experience uses React state and effects for scroll progress, active section tracking, project filtering, expandable project notes, responsive navigation, and the copy-email action. Icons come from **Lucide React**. The visual system uses Cormorant Garamond for display typography, DM Sans for readable interface copy, and IBM Plex Mono for technical metadata. GitHub Pages deployment is handled by a preserved GitHub Actions workflow.

### Data science and AI/ML

My data and machine-learning toolkit includes **Python, Pandas, NumPy, Scikit-learn, TensorFlow, PyTorch, and Hugging Face Transformers**. I use these technologies for data preparation, feature engineering, exploratory analysis, classification, regression, model evaluation, and applied AI experimentation.

### Development and delivery

I have used **Java, SQL, HTML, CSS, JavaScript, Flask, REST APIs, Streamlit, Joblib, Git, and GitHub**. These tools help me move between backend logic, model-serving concepts, web interfaces, and source-controlled project delivery.
